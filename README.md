
# 🌊 Ride and Roar – Explore Water Adventures Like Never Before!

## 📌 Project Overview

**Ride and Roar** is a beginner-friendly website built for water sports lovers. It helps users explore thrilling water activities like Jet Skiing, Kayaking, Scuba Diving, River Rafting, and more. Visitors can check locations, price ranges, and register directly. Owners can also register to offer their services through the platform.

Currently, detailed **location info and highlights are provided for Jet Skiing and Kayaking** (these can be seen by clicking on the images of jet ski and kayaking which are on the home page). Other water sports are also listed such as Scuba Diving, River Rafting, parasailing etc.

---

## 🔧 How to Open / View the Project

1. Download or clone the project folder.
2. Open the file named `rideandroar.html` in a web browser (Google Chrome).
3. Use the navigation bar to browse different pages like, Search by Location, Registration, FAQ, Reviews, and About Us.

> 💡 No installation required. It’s a fully static project using only front-end technologies.
